# Optimisation Timing Machine Specification

The Team F timing experiment was run on 2026-08-20 using:

- CPU: 12th Gen Intel Core i7-1265U
- RAM: 15.7 GB
- Operating system: Microsoft Windows 11 Pro
- Java: 26.0.1
- Timed runs: 3 per algorithm and input size, after one untimed warm-up
- Random seed: 204308

The same generated request list and budget were used for greedy and dynamic programming at
each input size. Results are stored in `data/results/optimisation-timing.csv`.
